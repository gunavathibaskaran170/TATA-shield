# SHIELD — Vehicle Structural Intelligence Command Center

**Tata EV engineering use-case prototype / Tata-inspired EV digital twin.**

An interactive, layer-based digital twin of a compact electric SUV. Built with React 18 + TypeScript + Three.js (react-three-fiber) + Zustand + Recharts.

---

## Getting Started

To run the SHIELD EV Command Center App:

```bash
cd shield-app
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## Features

- **Vehicle Twin**: 3D interactive model with component tree, layers, and realtime sensor telemetry.
- **Structural Intelligence**: Region-level strain/stress analysis and health assessment.
- **AI Diagnostics**: Anomaly detection and root cause analysis across vehicle structural zones.
- **Event Forensics**: Historical telemetry playback and load impact inspection.
- **Fleet Analytics**: Multi-vehicle health metrics and component deviation tracking.
- **Digital Thread & Structural Passport**: Manufacturing lifecycle traceability and provenance ledger.
