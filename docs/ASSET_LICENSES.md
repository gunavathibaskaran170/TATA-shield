# SHIELD — Asset Licensing & Provenance Declarations

## Overview
All 3D assets, procedural geometry, icons, and code in SHIELD are licensed under open standards or built procedurally within the codebase.

## 3D Vehicle Models & Geometry
- **Standalone Production SUV & Unibody Frame**: Procedurally lofted and assembled using Three.js parametric geometries in `shield-app/src/three/bodyShell.ts` and `ProductionSuv.tsx`.
- **Skeletal & BIW Assembly**: Custom parametric digital twin representations built for academic and demonstration purposes.
- **License**: MIT License.

## Iconography & UI Components
- **Icons**: Lucide React / SVG vector icons.
- **Typography**: Inter / System UI sans-serif fonts.
- **License**: MIT License / SIL Open Font License.

## Independence Declaration
SHIELD is an independent student/hackathon research project designed for structural health evaluation of electric vehicles. It does not contain proprietary OEM CAD or confidential vehicle platform data.
